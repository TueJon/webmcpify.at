# Product

## Register

brand

## Users

Web developers and teams evaluating how to make an existing application usable by
browser agents. They arrive with limited time, uneven familiarity with WebMCP, and a
need to distinguish a real integration workflow from an MCP server, browser agent,
or speculative demo. Their primary job is to understand the trust model, see proof
that the workflow works, and install the skill in their coding agent.

## Product Purpose

Explain and distribute webmcpify: an open-source agent skill that inventories an
existing web app, asks the human to approve a typed tool manifest, integrates WebMCP
through existing UI code paths, and verifies every tool in a real browser. Success is
an informed install or source review—not a vague impression that WebMCP is promising.

## Brand Personality

Exacting, mechanical, candid. The site should feel like a well-made technical manual
with an opinionated purple inspection stamp: confident about what is verified, precise
about what is experimental, and explicit about what the skill will not do.

## Anti-references

Do not resemble a generic AI SaaS landing page, an MCP-server directory, a neon
gradient “agent platform,” or a speculative standards scorecard. Avoid inflated
claims, invented protocol features, decorative dashboards, testimonial theater, and
visual polish that hides the actual install, manifest, diff, or verification evidence.

## Design Principles

- Show the artifact: manifests, tool calls, diffs, and runnable proof beat promises.
- Make trust inspectable: the human gate, server boundary, and mutation class stay visible.
- Teach through sequence: explain the pipeline in the order a real run follows.
- Keep the first action concrete: install the skill or read the source, with no funnel detour.
- Preserve experimental honesty: state the browser/spec status and update it with the source.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Preserve keyboard access, visible focus, semantic headings and
tables, language metadata, text alternatives, 4.5:1 text contrast, zoom/reflow on
narrow screens, and a reduced-motion path. Core product information and every install
route must remain available without JavaScript or analytics consent.
